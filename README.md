# Starter

[Agent Skill](https://agentskills.io) that scaffolds a Vanilla, React or Astro project (JS/TS) with Oxlint, Oxfmt, a CSS reset, Lightning CSS and an `@/` alias. Needs Node 22.23.4+/24.11+ and pnpm.

```bash
git clone https://github.com/judenns/starter-templates.git ~/Work/starter-templates
ln -s ~/Work/starter-templates ~/.claude/skills/starter   # or ~/.agents/skills/starter
```

Use: `/starter react my-app`, or "Create an Astro site called blog".
